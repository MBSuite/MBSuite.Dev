## 🎯 วัตถุประสงค์ (Objective)
ปรับปรุงหน้า Landing Page ของ `MBSuite.Dev` ให้:
1. แสดง **โครงสร้างราคาใหม่ 3 แพ็กเกจ + สิทธิ์ซื้อขาด (Perpetual)** อย่างชัดเจน ไม่สับสน
2. มีสวิตช์สลับ **รายเดือน / รายปี** (พร้อมป้ายกำกับประหยัดกว่า 2 เดือน)
3. มีการ์ดและตารางเปรียบเทียบ **"เช่าใช้ 3 ปี vs ซื้อขาด Perpetual"** เพื่อกระตุ้นยอดขายแบบซื้อขาด
4. ปรับข้อความของ **6 Standalone Suites** ให้เน้น "แก้ปัญหาให้เจ้าของธุรกิจ" มากกว่าการบอกแค่ Technical Spec

## 1. ข้อมูลส่วนราคาใหม่ (Pricing Section Spec)

- Badge สำหรับ Yearly: `🏷️ ประหยัดสูงสุด 17% (จ่าย 10 เดือน แถม 2 เดือน)`

#### Card 1: Starter (Single Suite - หน้าร้านเดี่ยว)

- **Subtitle:** เลือกระบบหน้าร้านเฉพาะทาง 1 ธุรกิจ (F&B, Retail, Rental, Hotel, Service หรือ Pharmacy)

- **Price Yearly:** `3,500` บาท/ปี (ตกเดือนละ ~291 บ.)
- **Perpetual Option:** หรือซื้อขาด `9,900` บาท (ติดตั้ง Docker บนเครื่องตัวเอง)
- **Features List:**
  - ✅ สิทธิ์ใช้งาน 1 โมดูลเฉพาะทางแบบ Standalone เต็มระบบ
  - ✅ ระบบขายหน้าร้าน / เช็กบิล / จัดการงานประจำวัน

#### Card 2: Professional (Core Accounting - บัญชีและภาษีกลาง)

- **Subtitle:** ระบบจัดการเอกสาร บัญชีรายรับ-รายจ่าย และภาษีไทย RD-Ready

## 2. ส่วนเปรียบเทียบ "เช่าใช้ vs ซื้อขาด Perpetual" (Perpetual Callout Section)

วางไว้ด้านล่างการ์ดราคา เพื่อโน้มน้าวกลุ่มที่ไม่อยากจ่ายรายเดือน:

```markdown
### 💡 เบื่อกับการจ่ายค่าซอฟต์แวร์รายเดือนใช่ไหม?
**เป็นเจ้าของระบบอย่างแท้จริงด้วย "สิทธิ์ซื้อขาด (Perpetual License)"**

| เปรียบเทียบระยะยาว 3 ปี | เช่าใช้ Cloud ทั่วไป | ซื้อขาด MBSuite (Docker) |
|---|:---:|:---:|
| ค่าบริการปีที่ 1 | 9,000 บ. | 19,900 บ. |
| ค่าบริการปีที่ 2 | 9,000 บ. | 0 บ. *(ใช้งานต่อได้ทันที)* |
| ค่าบริการปีที่ 3 | 9,000 บ. | 0 บ. *(ใช้งานต่อได้ทันที)* |
| **รวมค่าใช้จ่าย 3 ปี** | **27,000 บ.** | **19,900 บ. (ประหยัดกว่า 7,100+ บ.)** |
| ความเป็นเจ้าของข้อมูล | อยู่บนเซิร์ฟเวอร์ผู้ให้บริการ | **อยู่บนเครื่องของคุณ 100% ปลอดภัย ไร้กังวล** |

> 📌 ทุกแพ็กเกจซื้อขาดแถมฟรีอัปเดต 1 ปีแรก หลังจากนั้นสามารถเลือกต่ออายุอัปเดต (MA) เพียง 15-20% ต่อปี หรือเลือกไม่ต่ออายุก็ยังใช้งานเวอร์ชันเดิมได้ตลอดชีพ
```

## 3. ปรับปรุงการนำเสนอ 6 โมดูล (`PluginsModules.tsx`)

ปรับปรุงเนื้อหาการ์ด 6 โมดูลให้เน้น Pain Point ที่ตรงใจผู้ประกอบการ:

1. **F&B Suite (ร้านอาหาร / คาเฟ่):**
   - *คำโปรย:* "หมดปัญหาร้านวุ่นวายตอนลูกค้าเยอะ"
   - *จุดเด่น:* ลูกค้าสแกน QR สั่งอาหารเองได้ไม่ต้องรอพนักงาน, ส่งออเดอร์เข้าครัว (KOT) แยกแผนก, จัดการโต๊ะและเปิด/รวมบิลรวดเร็ว, คำนวณต้นทุนอาหารจากสูตรวัตถุดิบ
2. **Retail Suite (ค้าปลีก / ร้านสะดวกซื้อ):**
   - *คำโปรย:* "คิดเงินไว สต็อกไม่รั่วไหล ปิดยอดกะแม่นยำ"
   - *จุดเด่น:* หน้าจอ POS แคชเชียร์คิดเงินด่วน, ยิงบาร์โค้ดผ่านกล้องมือถือ/แท็บเล็ตได้, ควบคุมเงินทอนและลิ้นชักเก็บเงินตอนเปิด-ปิดกะ, ตัดสต็อกและเตือนของใกล้หมดทันที
3. **Rental Suite (หอพัก / คอนโด / ตลาด):**
   - *คำโปรย:* "ลืมการนั่งกดเครื่องคิดเลขจดมิเตอร์น้ำไฟไปได้เลย"
   - *จุดเด่น:* กรอกเลขมิเตอร์น้ำ-ไฟ คำนวณส่วนต่างคูณหน่วยอัตโนมัติ, สร้างใบแจ้งหนี้รวมค่าเช่าส่งให้ผู้เช่า, ตรวจสอบสถานะการจ่ายเงินและห้องว่างได้ในหน้าเดียว
4. **Hotel Suite (โรงแรม / ที่พักรายวัน / รถเช่า):**
   - *คำโปรย:* "จัดการห้องพักและการจองแบบมืออาชีพ"
   - *จุดเด่น:* ปฏิทินแสดงสถานะห้องพักแบบ Visual Timeline, ระบบ Check-in/Check-out จัดการเงินมัดจำ, บอร์ดแจ้งเตือนสถานะทำความสะอาดห้องสำหรับแม่บ้าน
5. **Pharmacy Suite (ร้านขายยา):**
   - *คำโปรย:* "คุมสต็อกยาปลอดภัย มั่นใจมาตรฐาน GPP"
   - *จุดเด่น:* แคตตาล็อกยาพร้อมรหัสยามาตรฐาน, จัดการสต็อกแยกล็อต (Lot Number) และวันหมดอายุ, ระบบตัดจ่ายแบบ FEFO (ยาหมดอายุก่อนตัดก่อน), แจ้งเตือนยาล่วงหน้าก่อนหมดอายุ
6. **Service Suite (งานบริการ / คลินิก / ศูนย์บริการ):**
   - *คำโปรย:* "นัดหมายแม่นยำ ติดตามงานบริการไม่มีตกหล่น"
   - *จุดเด่น:* ระบบลงทะเบียนและจองคิวออนไลน์, ตารางนัดหมายแบ่งตามผู้ให้บริการ, บันทึกประวัติการให้บริการและสัญญาบริการ, แจ้งเตือนการต่อสัญญาและรอบบำรุงรักษา
