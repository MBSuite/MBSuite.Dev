# แผนการดำเนินงานและลำดับขั้นตอนการพัฒนา (Action Roadmap)
> บันทึก ณ วันที่: 2026-11-09  
> ผู้บันทึก: อัล (พี่สี่) — สายงานระบบ/ผู้แทนพี่ฆัง  
> เป้าหมาย: แผนแม่บท 3 ระยะสำหรับปรับปรุง MBSuite ทั้งระบบตามมติร่วมกับพี่ฆัง

---

## 📌 Phase 1: ปรับปรุงหน้าร้านและโครงสร้างราคา (`MBSuite.Dev`)
> **สถานะ:** รอเริ่มดำเนินการ (Ready for execution)  
> **ผู้รับผิดชอบหลัก:** Kiro (UI/UX) ร่วมกับ อัล (พี่สี่)

- [ ] **1. อัปเดตส่วนแสดงราคา (`src/components/Pricing.tsx`):**
  - นำเสนอ 3 แพ็กเกจหลัก:
    1. Single Suite (350 บ./ด. หรือ 3,500 บ./ปี)
    2. Core Accounting (500 บ./ด. หรือ 4,900 บ./ปี)
    3. Complete Bundle (750 บ./ด. หรือ 7,500 บ./ปี)
  - เพิ่มแถบสลับ (Toggle): รายเดือน / รายปี
  - เพิ่มการ์ดนำเสนอตัวเลือกซื้อขาด **Perpetual License (9,900 / 14,900 / 19,900 บ.)** ติดตั้ง Docker
- [ ] **2. เพิ่มตารางเปรียบเทียบ "เช่าใช้ 3 ปี vs ซื้อขาด":**
  - แสดงตัวเลขการประหยัดต้นทุนและความคุ้มค่าระยะยาว
- [ ] **3. อัปเดตไฟล์ภาษา (`src/i18n/th.json` และ `en.json`):**
  - ปรับคำอธิบายจุดเด่นของ 6 โมดูลให้ตรงกับฟังก์ชันจริงและเน้นจุดขาย
- [ ] **4. Build & Type Check:**
  - รัน `pnpm run build` เพื่อตรวจสอบความถูกต้องก่อน Deploy

## 📌 Phase 2: ฟีเจอร์ชูโรงปิดการขายสำหรับตลาดไทย (Market Essentials)
> **สถานะ:** แผนงานระยะกลาง  
> **ผู้รับผิดชอบหลัก:** OpenCode / อัล (ระบบหลังบ้าน)

- [ ] **1. ระบบ PromptPay Dynamic QR พร้อมตรวจสลิปอัตโนมัติ (Slip Verification):**
  - สร้าง QR Code PromptPay ตามยอดบิลจริง
  - เชื่อมต่อ API ตรวจสอบสลิปโอนเงิน (เช่น SlipOK / EasySlip)
  - อัปเดตสถานะบิลเป็นชำระแล้วอัตโนมัติเมื่อตรวจพบยอดโอน
- [ ] **2. ระบบแจ้งเตือนสรุปยอดขายผ่าน LINE (LINE OA / Notify):**
  - ส่งสรุปยอดขายปิดกะประจำวัน (Daily Closing Summary) เข้า LINE เจ้าของร้าน
  - ส่งแจ้งเตือนเมื่อสต็อกสินค้าต่ำกว่าจุดสั่งซื้อ หรือยาใกล้หมดอายุ
- [ ] **3. ระบบพิมพ์ใบเสร็จความร้อน (Thermal Receipt Printer ESC/POS):**
  - รองรับการพิมพ์สลิปขนาด 58mm / 80mm ผ่าน Bluetooth / USB / LAN สำหรับหน้าร้าน F&B และ Retail

## 📌 Phase 3: เติมเต็มความลึก 6 โมดูลเฉพาะทาง (Module Depth & UX)
> **สถานะ:** แผนงานต่อเนื่อง

- [ ] **F&B:** สูตรอาหารตัดสต็อกวัตถุดิบ (Recipe/BOM) และฟังก์ชันรวมบิล/ย้ายโต๊ะ (Bill Merge & Transfer)
- [ ] **Retail:** ระบบเปิดกะ/ปิดกะ นับเงินสดในลิ้นชัก (Cash Drawer Management) และระบบสแกนบาร์โค้ดผ่านกล้องอุปกรณ์
- [ ] **Rental:** ระบบบันทึกมิเตอร์น้ำ-ไฟ (Utility Meter Entry) คำนวณหน่วยและออกบิลรวมอัตโนมัติ
- [ ] **Hotel:** ปฏิทินแสดงสถานะห้องพักแบบ Visual (Timeline Room Calendar) และบอร์ดสถานะงานแม่บ้าน
- [ ] **Pharmacy:** ตัดสต็อกแบบหมดอายุก่อนตัดก่อน (FEFO) และแจ้งเตือนยาใกล้หมดอายุล่วงหน้า 30–90 วัน
- [ ] **Service:** พอร์ทัลจองคิวและเวลานัดหมายออนไลน์สำหรับลูกค้า (Public Booking Portal)
- [ ] **Interactive Live Demo:** ปุ่มทดลองเล่นบนหน้าเว็บ MBSuite.Dev โดยไม่ต้องลงทะเบียน
