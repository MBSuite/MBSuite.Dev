# คู่มือสำหรับลูกค้า — เลือกและเริ่มใช้ MBSuite

เขียนสำหรับ **นักบัญชีและเจ้าของกิจการ** อ่านเข้าใจได้โดยไม่ต้องมีความรู้ด้านเขียนโปรแกรม
ใช้สำหรับอ่านก่อนทดลองใช้งาน และพิมพ์หรือบันทึกเป็น PDF ได้

---

## โปรแกรมทั้ง 7 แบบ

| # | โปรแกรม | เหมาะกับ | สิ่งที่เน้น |
|---|---------|----------|-------------|
| 01 | [Micro-Business-Suite](./01-micro-business-suite.md) | ทุกกิจการที่ต้องทำบัญชีและภาษี | เอกสารขาย รายจ่าย สมุดรายวัน รายงาน |
| 02 | [Micro-Business-Hotel](./02-micro-business-hotel.md) | โรงแรม เกสต์เฮาส์ ที่พัก | ห้องพัก การจอง งานแม่บ้าน |
| 03 | [Micro-Business-Pharmacy](./03-micro-business-pharmacy.md) | ร้านยา ร้านค้าด้านสุขภาพ | ทะเบียนยา ล็อต วันหมดอายุ ใบสั่งยา |
| 04 | [Micro-Business-Rental](./04-micro-business-rental.md) | ผู้ให้เช่าห้อง/อสังหา | ทรัพย์สิน สัญญา ค่าเช่า งานซ่อม |
| 05 | [Micro-Business-Service](./05-micro-business-service.md) | ธุรกิจให้บริการ ที่ปรึกษา | นัดหมาย สัญญาบริการ แจ้งเตือน |
| 06 | [Micro-Business-Retail](./06-micro-business-retail.md) | ร้านค้าปลีก ค้าส่ง | ขายหน้าร้าน สินค้า สต็อก |
| 07 | [Micro-Business-FNB](./07-micro-business-fnb.md) | ร้านอาหาร คาเฟ่ | QR สั่งอาหาร โต๊ะ ครัว ต้นทุนอาหาร |

**อ่านบนเว็บได้ที่:** `/documents/products` ของเว็บ MBSuite.Dev

## เลือกอย่างไรให้ตรงกับกิจการ

- **ต้องการทำบัญชี ออกเอกสาร และดูภาษี** → เริ่มที่ **Micro-Business-Suite (Core)** เป็นโปรแกรมหลัก
- **ขายของหน้าร้านและมีสต็อก** → **Retail** (หรือ Core หากต้องการรวมบัญชีด้วยในระบบเดียว)
- **ขายเวลา/บริการ มีนัดหมายและสัญญา** → **Service**
- **มีห้องเช่าหรือทรัพย์สินให้เช่า** → **Rental**
- **มีที่พักและต้องดูห้อง/แม่บ้าน** → **Hotel**
- **ขายยา ต้องระวังวันหมดอายุ** → **Pharmacy**
- **มีโต๊ะ ให้ลูกค้าสั่งเอง และต้องรู้ต้นทุนอาหาร** → **FNB**

โปรแกรมเฉพาะทางทั้ง 6 แบบทำงานได้อิสระ และมีช่องให้ผูกกับระบบบัญชีหลัก (Core) เพื่อส่งข้อมูลด้านการเงินไปรวมกัน

## สิ่งที่ควรเตรียมก่อนทดลอง

1. **ข้อมูลกิจการ** — ชื่อกิจการ ที่อยู่ และเลขประจำตัวผู้เสียภาษี (ถ้ามี)
2. **รายชื่อสินค้า/บริการ** และราคาที่ใช้จริงอย่างน้อย 2–3 รายการ
3. **ข้อมูลลูกค้าหรือผู้ติดต่อ** 1–2 รายการ
4. **เอกสารจริง 1 ชุด** เช่น ใบเสนอราคา ใบแจ้งหนี้ ใบเสร็จซื้อของ เพื่อลองบันทึกและเทียบผล
5. **เวลา 30–60 นาที** สำหรับลองทำขั้นตอนหลัก 1 รอบ

> ระหว่างทดลอง ควรใช้ข้อมูลจำลองหรือข้อมูลจำนวนน้อยก่อน แล้วค่อยนำข้อมูลจริงเข้ามาเมื่อมั่นใจ

## ข้อควรระวังที่ใช้ได้ทุกเล่ม

- รายงานภาษีเป็น **ข้อมูลช่วยตรวจทานและเตรียมแบบ** ไม่ใช่การยื่นแบบแทน และไม่ใช่การรับรองความถูกต้อง
- กำไรในรายงานอาจนับตามวันที่ออกเอกสาร (คงค้าง) ขณะที่กระแสเงินสดนับตามวันที่รับ–จ่ายจริง ควรอ่านแยกกัน
- บางอย่างยังทำผ่านหน้าจอไม่ได้ในขณะนี้ เอกสารแต่ละเล่มจะระบุไว้ในหัวข้อ **“ควรรู้ก่อนทดลอง”** ตามความจริง
- ถ้าต้องการให้เพิ่มข้อมูลที่ยังทำผ่านหน้าจอไม่ได้ หรือปรับค่าเบื้องหลัง ติดต่อทีมงาน Microtronic
- ก่อนใช้งานจริง ควรตรวจข้อกำหนดภาษีและเอกสารต้นทางให้ตรงกับข้อกำหนดปัจจุบันเสมอ
